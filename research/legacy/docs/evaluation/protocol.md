# P0 质量与效率评测协议

状态：方法要求；实体身份、关系语境、事件整体匹配等具体评分键在 #16–18 结合真实标注冻结，当前没有结果或通过门槛。

## 质量

precision = TP / (TP + FP)，recall = TP / (TP + FN)，F1 = 2TP / (2TP + FP + FN)。每个指标按自身分母判断是否为 N/A；同时保留计数。严格一对一匹配为主，宽松匹配另报。

分别评测实体提及、身份对齐、属性、关系、事件论元、带语境主张和最终图谱。实体正确不能代替关系正确，字段校验通过不能代替任何语义正确率。

评分仅在声明穷尽标注的文本范围与类型集合内计算；范围外输出列为未评估并报告比例。解析失败、拒答、过滤和装配丢失导致的已标注内容未输出仍是 FN。

重复记录不增加 TP；上下文不同的主张不错误去重。不能依赖随机节点 ID 判断正确性。装配前后分别对账以区分模型错误与构图错误。

报告 micro、明确类别纳入规则的 macro、各类型、长短文、代表性集与困难集，以及错误归属、错误合并、无依据补写。引用能定位和引用支持语义分别核验。

## 效率

端到端计时覆盖读取、预处理、模型、校验、身份对齐、装配与可选写入。另报阶段时间、秒／文书、docs/min、p50/p95、token、调用数、失败和重试、内存峰值。

记录硬件、模型标识、上下文预算、文档长度和并发。冷启动、预热、缓存命中分别计量；Spark 统一内存不把主机与 GPU 占用直接相加。

## 冻结与比较

先得到开发集基线，再明确可接受质量下限，正式测试前冻结。相同数据、语义输出契约与预算下比较 Qwen、本体约束、Qwen 复核及 OpenJev 辅助；不得仅因省略内容而认定提效。

正式测试不参与调参。保存逐案结果和不确定性估计；小样本只用于原型判断。没有人工 gold 的子任务明确标为待评估。
