# 语境包围范围与直接断言来源：契约 0.3 / 抽取 v12

由 v11 的真实失败推动：引用子语境 u53–u62 挂在只覆盖 u44–u52 的父语境下，且没有另一个结构包含它的父语境。新版本由原文重新声明两类范围，不重写旧失败或自动扩大旧父范围。

| 层 | 字段 | 含义 |
| --- | --- | --- |
| 模型草稿 Context | enclosing_units | 包围当前上下文及其子语境的原文片段 |
| 模型草稿 Context | assertion_units | 本陈述者直接断言的片段，不继承子引用 |
| 最终记录 Context | evidence | 包围范围的精确原文跨度，不表示采信或事实成立 |
| 最终记录 Context | assertion_evidence | 直接断言范围的精确原文跨度 |
| 候选图 | covers / assertion_source | 分别保存两类证据关系；还原时不能混合 |

验收要求：直接来源在包围范围内；父包围范围包含子包围范围；父直接来源与任何直接子包围范围不重叠；包围范围由直接来源和直接子范围共同覆盖，不能有未分配的内部空洞；叶语境必须有直接来源。允许没有自己断言的纯结构容器，但必须有子语境并明确记录免调用原因。角色、事件和所有属性的证据都必须在所属语境直接来源内。原文提及补充阶段同样只能看到当前直接来源片段。

结构示意（不是案件）：父包围片段 u0/u1/u2，直接片段 u0/u2，引用子语境 u1。父抽取请求只提供 u0/u2，子请求只提供 u1。父不能因结构包含 u1 就拿它作为事件或金额证据；若法院有后续独立认定文字，需独立的归属与直接来源。

实现：版本化 `ontology/private-lending-v0.3.json`、生成 Schema、来源与范围校验、图装配/还原、v12 头部和逐语境请求、零调用回放。源码复用旧编译器的坐标与保守值归一化逻辑，最终记录必须通过完整 0.3 验收；不存在自动把旧 0.2 候选升级的路径。历史契约、提示及原响应保留，默认 v5 不变。

运行时先校验首阶段两类范围，失败则不调用子阶段；通过后冻结范围/陈述者/主体。逐语境生成只接收 `assertion_units` 原文，Schema 也绑定其 ID。任何阶段失败均拒收整篇；不发布半篇、不默认选位置、不扩大范围或删除引用。阶段账本保存包围/直接范围、未分配原文单元和执行状态，零调用回放重建所有请求并逐字核对中间产物。

独立试验配置 `configs/qwen-extraction-v12-pilot.json`，调用已有 spark-lan:8003、温度0.2、seed42、逐阶段8192输出上限。使用完整36篇来源清单，先注册并仅选择同一已阅Spark4396来源。不是8K/16K测速，不扩样、不调用新云端API、不改变模型服务。真实结果需试跑后单独登记；契约/回归通过不证明整篇抽取或法律语义正确。

限制：原文单元仍按标点划分，一个单元若同时包含外层与引述，需要后续更细但可回放的划分。语境类型、陈述者归属、参与角色、遗漏仍是语义风险；新增范围约束不构成独立gold或整体P/R/F1。
