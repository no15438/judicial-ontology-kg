# 证据前置生成与独立归属审查

2026-10-05；适用于 `codex/jev-shadow-evaluation`。这份设计区分已实现的工程控制和待实现的语义审查，不能以方案代替实验结果。

## 当前问题的分类

| 观测 | 问题性质 | 工程处理 | Jev 的作用 |
| --- | --- | --- | --- |
| 模型把全角空格复制为普通空格 | 字面输出漂移 | 枚举源位置，保存原字，显式选择候选 | 不负责字符修复 |
| 同一称谓出现多次，单元或 occurrence 错误 | 位置歧义 | 有限位置目录、作用域过滤、引用校验 | 可审查候选是否属于目标主体 |
| 模型把原文简写后当引文 | 摘要与证据混淆 | 事实生成前构造不可变证据目录，不再让模型复制引文 | 判断实际引文是否支持事实 |
| 金额在语境内，但不在所选转账事件证据中 | 事件来源不一致 | 事件内引用检查；不能自动扩大范围或借其他事件金额 | 判断补充来源是否确实属于同一事件 |
| 法院转述被标成法院认定 | 陈述层次错误 | 保留发言者、直接语境、引用层次 | 独立有限选项分类；不确定保留 |

## 数据流与边界

1. **程序准备来源**：保存不可变原文、哈希、分句单元和位置。正则只枚举字面候选，不判定法律事实。
2. **Qwen 建立主体与语境**：先发现具名主体，再选择原文提及；冻结主体目录，生成有明确直接来源范围的语境。
3. **程序先编译证据目录**：保留当前直接语境内的完整单元与数字/日期字面片段。每个候选绑定唯一原文位置，同字不同位置保持独立。
4. **Qwen 生成事实并引用目录**：角色、事件、属性、极性使用既有主体和证据 ID，不自行重写引文或计算偏移。
5. **程序验证与编译**：检查所有 ID、原文哈希、语境权限、事件证据归属以及完整契约。位置还原成功不代表归属正确。
6. **独立语义审查（下一阶段）**：Jev 接收目标事实、候选证据和相邻原文；独立输出支持、反驳或不足。相邻内容不自动成为证据。保留原结论、审查输出、分歧和拒判；不将一致票当 gold。
7. **有界修复（尚待实现）**：按错误类别只重做失败阶段，冻结无关主体和语境；保留首轮结果、差分、调用预算和再次验证结果。程序定位错误不用再问模型，语义冲突才交给审查/生成器。
8. **装配与回放**：整篇契约通过后才装配图；离线请求回放和图反向还原独立验证。不能发布半篇冒称整篇成功。

## 当前实现与验收顺序

- v17–v19：空格变体位置目录、冻结主体增量、语境 ID 程序化。
- v20：提及归属与事实生成分离。
- v21：属性生成后再选位置；真实运行仍有事件证据归属拒收。
- v22：事实生成前提供原文证据目录；真实测试仍因转账属性选择其他事件单元而拒收。
- v23：先生成并冻结事件骨架，再为每个事件提供独立属性 Schema，合法证据 ID 枚举只含该事件范围。完整属性阶段必须给出每个事件的结果，禁止新增、删除或重写事件。
- v24：进一步为 predicate 提供相应字面类型的证据选项；固定类型由程序推导，其他类型不能通过重复填写 kind 覆盖。词法目录并不完备，特殊日期/金额需要后续显式扩展，不能将其覆盖当语义 recall。
- v25：明确同一集合指代位置允许分别关联多个确定成员，保存独立 Mention/Actor；不确定成员仍拒判，不创造合并主体。
- v26：提及传输改为位置→主体→类型的对象映射。同位置同主体只出现一次，已有锚点类型在 Schema 中冻结；集合成员仍分别保留。原始响应及展开回执可回放。
- Jev 已有独立语境分类影子实验；尚未接入 v22 的逐事实支持性审查，不宣称本轮已由 Jev 复核。
