# 项目定位与工程目标

当前定位：**可溯源的司法关系检索与证据工作流**。真实民间借贷文书用于检验：系统能否区分陈述来源、保留有据关系、执行受约束的关系查询，并返回能回读原文的证据。沿用 judicial-ontology-kg 仓库和已有契约。

用户指定的“项目集思广益”讨论提供了两点设计启发：围绕真实关系查询发展最小模型；将工作流编排、上下文管理、失败恢复、调用追踪、回放和任务评测作为明确工程成果。讨论中的招聘状态、岗位匹配评分和模型置信度示例不作为本项目事实或技术验收依据。

## 使用者与第一项任务

使用者为需要核对案件材料的研究人员。第一项任务限定为同案关系核查：某笔款项由谁向谁支付、原文如何描述其用途，以及当事人与法院对此分别如何表达。输出包括有来源的候选关系、不同来源之间的分歧、未决部分和逐边原文引用。

例如，查询转账双方与某项目的关联时，可以返回文书中明确记录的关系路径；不能从“款项用于项目”推导“项目是借款人”，也不能从“款项不是借款”推导“转账未发生”。跨边拼接只表达记录间的连接，不自动证明资金流、代理、控制或法律责任。

普通证据问答和段落检索以文本为默认入口。图层用于有明确关系约束的直接关系、同案2–3跳路径和共同节点查询。对返回的每条边检查来源语境、时间及引用；主体身份没有明确来源支持时不拼接路径。

## 现有基础与缺口

- 已有：版本化来源适配、原文索引、中文抽取协议、位置对齐、局部修复与隔离、调用留档、无损图装配和零网络回放。固定20篇在旧冻结实现aa01d59上20/20工程通过，语义P/R/F1仍为空。
- 本轮已实施（修复与弃权分别验收）：分别选择语境类型和实际说话者、逐断言检查内层来源、有界语境重抽与拆分、原角色/事件/陈述及既有未决的去向账本、对齐共享原文目录。这些新增能力须由新实测单独验收，不能借用旧20/20结论。
- 尚缺：可靠的同案主体复用、属性标准化、任务驱动的路径查询、独立查询参考与文本/图对照、实际本地模型token预算。
- 当前是受约束的模型工作流；尚未实现通用自主规划Agent、长期记忆、沙箱或模型训练，不将固定流水线包装成这些能力。

## 工程交付的具体边界

抽取、对齐、来源语义复核、证据复核及编译是可追踪的分步工作流。保存各阶段输入、调用结果、失败原因和原候选去向；有界恢复后仍无法表达时保留未决，原文检索继续可用。新流程必须从完整原文做独立新抽取，并能零网络重放；历史候选上的诊断单独报告。

当前没有专家图谱gold，评测先落到可核验任务：引用是否精确；回答是否把诉请误说成裁判支持；转账性质的否定是否被误说成未转账；返回路径中的每一步是否有同案直接证据。来源审查与规则反例不覆盖全部法律语义；模型自报信心不能补足这个缺口。

## 分阶段验收

| 阶段 | 交付 | 验收和退出条件 |
| --- | --- | --- |
| M1 来源语义可靠性 | 说话者、原审/当前法院、嵌套转述、否定对象、请求/支持值、时间属性的反例集与修复流程 | 原始失败保留；候选被正确归属或显式未决；严格原文跨度、契约和回放继续通过；报告修复与弃权分别计数 |
| M2 同案关系工具 | 来源支持的主体复用及最大3跳路径查询；每条边可回读，过滤语境和极性 | 不按同名跨案合并；没有可支持路径时返回未决/未找到；路径连接不能冒称法律推论 |
| M3 用途与增益 | 从原文独立登记直接关系、路径与否定反例；文本检索+同模型阅读对照文本+关系工具+同模型阅读 | 同查询、语料、模型及预算；报告证据命中、来源归属、弃权、调用/token成本与延迟；缺少参考覆盖的任务不算P/R/F1 |
| M4 本地迁移 | 同一冻结流程在局域网模型重新抽取、追踪和回放 | 实测模型/tokenizer/模板及总上下文预算；不复用云端响应，不修改Spark服务；相同任务条件下报告质量与成本 |

新增专家gold不以用户法律标注为前置条件。可单独审查原文明确陈述的来源与位置；法律解释、全图召回和真实身份正确率保持未验证。未知项、模型判断和规则线索都不称为gold，不用LLM生成的置信度数字替代校准或验证。

跨案网络、控制/利益模式、司法引用网络和大规模图算法待明确身份与对应真实查询后再做。训练、生活助手、多Agent团队也不作为当前交付的依赖。

项目最终应证明关系工具是否改善任务。图层没有可证增益时保留可靠文本检索、来源工作流和评测资产，停止扩大图抽取。简历可展示已验证的失败恢复、上下文优化、追踪和回放，不使用未经证明的准确率或增益。

## 本轮结果带来的下一项目标

新来源检查能够阻止已知“欲证明”内容成为法院确定事实，但该段仍被整体弃权，法院自身的明确表述未可靠保留。下一轮细化原文来源区间与引用层次，优先做到局部保留，而非继续堆叠复核；风险线索须随原文交给模型。验收同时记录有用输出覆盖和弃权范围，减少重复恢复调用。

完整新抽取在不同冻结版本分别2/2、2/2及1/1工程通过并回放；没有新增20篇语义结论。最后源码15ea8b3的范围补丁仅完成新窗口实测（整段未决）与889项工程测试，完整重抽结论不能从旧版本继承。具体数据及成本见 [进度](progress.md)和 [汇总](../research/source-semantic-summary-report.json)。
