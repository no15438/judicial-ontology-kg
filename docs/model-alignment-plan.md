## 目标和边界

让原文有依据、但位置或局部绑定不一致的候选自动归位。模型负责选择，程序只枚举有限候选、验证选择和生成派生结果；不直接修改图谱，不以通过数最大化为目标。

第一阶段实现原文位置与语境内引用绑定。实体别名/跨语境合并、类型调整和归属转换留在后续受控实验，不在本轮偷偷放宽。空白映射保留完整称谓与原字符偏移。候选缺失不属于对齐成功，unknown不强选。

## 顺序

1. 保留125条原问题，增加可解释诊断；按定位、索引依赖、证据范围、验证器拒绝、协议/运输失败分别报告。诊断复用旧响应不算新抽取。
2. 校验百炼System One接入；每批至多16个有限选择题。逐题含unknown选项，保存请求、概率与选择。概率不解释为法律正确率。
3. 同一批候选比较不对齐、Flash有限选择、decision-model-preview有限选择；正序/反序检查选择稳定性。不将相互同意当gold。
4. 对齐在现有复核前执行；与支持性复核职责分开：对齐找对应，复核查支持。后续若证据表明重复再合并，当前不省略归属/极性校验。
5. 冻结实现后从原文新跑固定文书，保存抽取前后账本和零网络回放；不得把旧响应诊断称为首轮成功。
