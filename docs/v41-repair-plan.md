# 二十篇实验后的修复设计

当前基线是冻结的v40云端Max二十篇，20篇全部结束、0篇整篇工程接受。最终分类与费用见research/bailian-twenty-v40-final-summary.json。失败不改写，本轮旧响应只用于离线错误回归，不算新抽或语义gold。

## P0 原文位置映射（本轮已实现）

v41在对象分类之前生成来源映射账本。只将U+0020和U+3000组成的连续空格映射到一个检索空格，同时保留每个映射字符对应的原始起止位置；不改写原文、不删除空格、不做标点/姓名/数字模糊匹配，不跨来源单元。所有原文出现均保留。

每个提议记录原字符串、全部候选证据、输出形式与输出索引。只有候选具有唯一原文字面形式时，才能将该字面形式交给既有分类和身份绑定；多个出现不是同一身份的证明，仍由逐位置绑定处理。不同原文形式发生碰撞则拒收为source_form_mapping_ambiguous，不自动选择。多个提议落到同一原文形式时合并下游重复输入，但账本保留全部提议。

六份实际失败的发现响应已离线回归：每份一个空格形式被映射，六份均不再存在该阶段的定位缺口；这是单阶段回归，不能记成六篇抽取通过。人工数据、模型响应仅保存在旧工作树忽略目录。

## P1 结构输出与异常诊断（待实现）

逐个检查anonymous-forms、mentions、header的实际错误。区分空绑定、错误字段、解析异常，禁止笼统protocol_invalid_response吞掉定位信息。ID、哈希、派生索引由程序生成。只对形式错误做有界结构重试，身份未决不得用默认值填充。先用保存失败响应回归，再验证新的完整请求。

## P2 未决身份与语境（待实现）

设计独立的未决提及/未知成员集合表示，保留原文、语境、候选与原因；禁止创建猜测主体。候选审计产物与可供检索的已验证记录分开，不能把部分成功变成整篇接受。语境划分先独立校验并冻结，再生成依赖语境的事件事实。

## P3 云端Flash完整回归（待执行）

以百炼官方qwen3.8-flash ID核实项目权限和计价，取消模型/价格硬编码，所有云端运行共用累计200元预算祖先账本；不照搬Max价格。先代表性小样，固定版本、来源、参数、预算进行从原文全新抽取，记录未经纠正首轮和自动修复后结果；通过后再执行同一20篇，不筛掉失败案。云端Flash与本地量化Next Flash不能当成完全相同模型。

验收包括原始证据逐字回放、零调用回放一致、歧义保持拒收、未决不丢失、调用次数/耗时/费用；整体法律语义P/R/F1仍无gold，不宣称已验证。正在运行的旧批次不改代码或切模型。
