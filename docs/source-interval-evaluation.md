# 来源区间与新文书一次性评测

## 实现

在模型产生事实候选之前，仅以原文划分连续的来源区间。每个目标单元恰好属于一个区间；不能遗漏、重叠、跨字段或改写原文。转述或引用区间保留可精确定位的外层引导句parent_cue。类型与引用方式是模型假设，不写成已经核验的标签。

区间分别提议、来源复核、对齐、证据核验及编译。主体提及仍可使用背景原文；关系证据必须来自当前目标。来源判断失败时只处理该区间，不回滚其他区间。失败仍按有界恢复、最终未决/硬失败记账，不修改候选图。来源复核同时看到风险检查所使用的相邻原文，避免只收到错误代码。

区间划分本身最多两次协议修复；无法取得完整合法划分时按窗口失败与有界分割处理，不静默回到一个大语境。零网络回放比较源区间账本及候选、图谱、覆盖、问题和映射。新运行明确source_partition=true；历史manifest缺省false以保留旧协议，历史回放须对应冻结源码。

该实现能验证位置、分区和依赖隔离，不能证明来源分类正确。有限区间也可能切开关系所需的证据、增加调用或扩大局部弃权；这些作为本轮观察指标，不掩盖在工程通过率后面。

## 本轮冻结策略

用户要求后续换一批文书，防止对反复使用的开发文书过拟合。先冻结实现，再从固定发布版AppealCase全量来源登记20篇：两审上游案由均为民间借贷，来源不在quarantine；不按抽取结果、语义难度或篇幅挑选。已有开发暴露、保守同案/配对/案号引用合组、精确正文重复全部排除。每个新组最多选一篇。

顺序由seed=source-intervals-heldout-20261007-v1与document_id的哈希决定。除标题/落款的正文采用NFKC及空白折叠后5字符shingle；两文各至少200个shingle时，Jaccard>=0.80或较短正文包含比例>=0.90视为近重复。归一化仅用于筛选，保存及模型输入仍为未经改写的发布原文。筛选对全部登记的旧开发来源及已入选新来源执行。

这仅证明按项目暴露记录隔离，不证明模型预训练未见，也不证明跨语料程序关联穷尽。未经曝光的范围限定于本项目，源文件和案号分组仍有上游局限。全部名单与哈希在API前登记；有失败不换样本，不复用历史响应、不人工改图、不与旧20拼接。整批结束前不按新样本输出改提示、规则或阈值；读完结果后该批视为开发暴露，下一次用于证明泛化须再取新组。

模型qwen3.8-flash，温度0.2、seed42、max_tokens8192、thinking=false；按文书并发6，文书内阶段顺序执行。累计授权200元；开始累计134.8362131元，本批子预算30元，累计上限164.8362131元。成本是保守配置估算，非账单。达到预算保留全部未完成项，不自动追加预算或换模型。
